Phone: watch, look, learn

On a phone the app sails the exercise and explains it in plain words. The part that is working lights up on the boat. There are no rope controls, only a few small buttons.

Try the highlight styles. In the app the part itself would light up in 3D. Here a ring stands in for it.

Below the card: Learn (tap a part), Watch (the exercises) and Sail, a simple mode where you only steer and set the speed, and the app trims the sails. Sail is for later; it is drawn here so you can see where it would go.
