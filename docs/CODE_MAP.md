# Code map

Where things are, so a session can go straight to the right file instead of searching. One line per file; the file's own header comment has the details. **Keep it current:** a PR that adds, removes or renames a file, or moves a responsibility, updates this map in the same PR.

## How a frame runs

`src/main.ts` (M58: first puts the chosen or linked boat in place with `useBoat`, then loads the app) → `app/app.ts` builds the layout, the 3D scene and the panel, then runs the frame loop: each `requestAnimationFrame` dispatches `{ type: 'step', dt }` to the store (`app/store.ts`), which advances the pure model (`model/sim.ts` and the Phase 2 modules, order in PHASE2_SPEC 4.2), then the renderers and panels read the new state. On the screen, the 3D view fills the page; over it sit the chip row (the camera chip and "!" on a phone; on wider screens also the mode chip and the gear), the mini-map and the info card; the panel is a sheet on a phone (`ui/sheet.ts`, with five tabs under its handle from M51, `ui/panelTabs.ts`), docked on the right in the side layout, and on screens 1,280 px wide or more has a second column (`ui/panel.ts`); its content is a list of sections ordered and opened by the mode (`ui/modes.ts`). UI code only dispatches actions; it never changes state directly. `app/urlSync.ts` writes the state into the address bar.

Store actions: `step`, `setClock`, `setClockShown`, `setMiniMap` (M28), `setFenders` (M33), `thruster` (M41: a joystick held to port or starboard, or let go), `line`, `clearPropeller` (M44: a command on a mooring line; a diver frees the propeller), `goToPlace`, `setMarinaLayout`, `setTraffic` (M42: puts the boat in a place, ready for harbour work, in a fresh state), `windlass` (M46: a windlass button held down or up, or let go), `silenceAnchorAlarm` (M46), `setControls`, `select`, `openLearn` (the Learn tab's entry, M20), `reset`, `load` (from a link), `setCameraPreset`, `setDetail`, `setLabels`, `setDebug`, `setStep`, `setPaused`, `setRopesMode`, `realistic` (Realistic-mode gestures), `setBoatMode` (Held still / Sailing), `autopilot`, `setWindMode`, `newWindPattern`, `setWindSize`, `setTimeBar`, `setTimeScale`, `setSeaSetting`, `repairSails`, `engine` (start, stop, lever).

## `content/` (data, no code)

| File | What |
|---|---|

| `lang/<code>/ui.json` | UI strings of one language, read through `t()` (`ui/i18n.ts`); `en` and `ru` (M23: same keys in the same order, tests list what is missing). |
| `lang/latin-words.json` | M23: the Latin words allowed on a Russian screen (instrument letters, makers, the foreign words that alternative-name notes quote); the boat's label words are allowed too. Used by `tests/languages.test.ts` and the browser Latin scan. |
| `lang/<code>/glossary.json` | The Learn entries of one language (names, other names, one-liner, what it does, on this boat, mistakes, show-me text), by registry id. `en` is the source language; `ru` is an AI draft (names and full text for every id: the M20, M21 and M22 entries). | `areas/adriatic.json` | A sailing area (position, time zone, fetch per Waves setting, the practice buoys, the default clock; M42: the places and the marina; M59: `marina.fendersHintM`), loaded by id (`model/area.ts`). |
